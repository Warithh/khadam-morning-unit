# خطة خدام الوحدة الصباحية

صفحة واحدة لتوزيع واجبات خدام شعبة المنشآت الصحية. تفتح من المتصفح، وتحفظ التعديلات فيه.

- **التوزيع**: انقل المنتسب لموقع **هذا اليوم فقط**؛ كل يوم مستقل عن غيره، ثم انسخ تقرير الواتساب.
- **المنتسبون**: الاسم، يوم الاستراحة، الإجازة، والملاحظة.
- **المواقع**: أسماء المواقع وتفصيلاتها، مع خيار «جمعة فقط».

من كان في يوم استراحته أو مجازاً لا يدخل التوزيع. صحيات الرابطة، ومتنقلة گراج أبو تراب، واستراحة المرتضى تُفتح يوم الجمعة فقط.
