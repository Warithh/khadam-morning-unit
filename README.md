# خطة خدام الوحدة الصباحية

توزيع يومي لخدام شعبة المنشآت الصحية مع تقرير واتساب.

- **التوزيع**: عرض يوم الدوام وتقرير الواتساب في بطاقات.
- **المنتسبون**: تعديل الاسم والاستراحة والإجازة وموقع العمل؛ كل منتسب مرة واحدة.
- **المواقع**: أسماء المواقع وتفصيلاتها فقط.
- **الإعدادات**: المواقع الثابتة (مثل حسن عبود في موقع الغسل)، تصدير/استيراد JSON، واستعادة الخطة الأصلية.

من كان في يوم استراحته، أو مؤشراً مجازاً، لا يدخل التوزيع. صحيات الرابطة، ومتنقلة گراج أبو تراب، واستراحة المرتضى تُفتح يوم الجمعة فقط. المنتسب المثبت لا يُنقل موقعه إلا بعد فك التثبيت من الإعدادات.
