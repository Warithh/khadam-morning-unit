# خطة خدام الوحدة الصباحية

صفحة واحدة لتوزيع واجبات خدام شعبة المنشآت الصحية. تفتح من المتصفح، وتحفظ التعديلات فيه.

- **التوزيع**: عرض يوم الدوام وتقرير الواتساب.
- **المنتسبون**: تعديل الاسم والاستراحة والإجازة وموقع العمل؛ كل منتسب مرة واحدة.
- **المواقع**: أسماء المواقع وتفصيلاتها فقط.

من كان في يوم استراحته، أو مؤشراً مجازاً، لا يدخل التوزيع. صحيات الرابطة، ومتنقلة گراج أبو تراب، واستراحة المرتضى تُفتح يوم الجمعة فقط.
